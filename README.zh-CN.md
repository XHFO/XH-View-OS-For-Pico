小纸 Pico 是深圳思维重置科技有限公司旗下小纸 Read 系列的开发板，面向墨水屏开源固件开发者，
搭载 ESP32-S3 和 4.7 寸单色墨水屏。本仓库是随板发布的出厂固件。

固件为显示、触摸、加速度计、电源、按键、TF 卡、字体、睡眠与唤醒提供独立的演示页和诊断页，
用于逐项确认硬件状态，并为自有固件提供刷新策略、功耗处理和交互方式的参考实现。

板级支持、PMU 协议主机端和芯片驱动均为可独立复用的组件。这是一份硬件演示固件，并非完整的阅读器产品。

面向 AI agent 的目录职责、`app_desc_t` 契约、术语表和注释规范见 [AGENTS.md](AGENTS.md)。

## 编译与烧写

需要 ESP-IDF v6.1。`components/read_pico/read_pico_flash_hpm.c` 依赖 v6 才提供的
`esp_flash_chips/spi_flash_override.h`。

```sh
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/cu.usbmodem* flash monitor
```

`sdkconfig.defaults` 中的 120 MHz flash / PSRAM 时序依赖板上实际的 flash 型号。
CI 使用 `sdkconfig.ci` 换回默认时序，仅验证能否编译通过，见
[.github/workflows/build.yml](docs/ci/upstream-build.yml)。

如果在固件开发或烧录时，设备从睡眠状态唤醒后无法被识别，请依次尝试：

1. 更换 USB Type-A（标准 USB）数据线。
2. 对设备重新执行一次睡眠和唤醒操作。
3. 重启开发板后重试。

面板公共电压（VCOM）在出厂时标定并写入 PMU。固件开机读取一次用于配置驱动，
不在本地保存，也不提供修改入口。

## 原生系统的配网与传书

灵犀画板在设备支持时直接通过调试 USB 接收画面，不导出 TF 卡，阅读器仍可使用卡内内容。自动更新仅后台保存；手动发送可选择当前触摸结束后立即展示，已锁屏时保持锁屏。文件管理仍使用独立的 TF 磁盘交接，完成后需安全弹出。

当前原生系统为 **XH View OS For Pico 0.39.1-dev69 · 先行预览测试版**。“系统设置”按用途分为六组：

| 分组 | 功能 |
| --- | --- |
| 存储与传输 | 直接打开统一入口：同一 Wi-Fi、设备热点、USB U 盘、TF 卡与笔记、打开本机图书 |
| 网络与连接 | Wi-Fi、手机与电脑管理、蓝牙翻页器 |
| 阅读与输入 | 阅读排版、笔记输入 |
| 外观与操作 | 首页导航、快捷菜单、提示音 |
| 应用与服务 | 应用集、Home Assistant、3D 打印机、棋类小游戏 |
| 系统与电源 | 电源与锁屏、日期与时间、保持唤醒 |

轻点顶部系统信息卡进入“关于本机”，可查看完整系统名、测试版标识与版本，并重新打开“首次使用引导”。子设置先返回所属分组，再返回设置首页和来源页面。

静态启动页同步显示系统名、版本与测试版标识，使用屏幕原生 16 灰阶。

“系统设置 → 系统与电源 → 保持唤醒”默认开启并记忆用户选择。开启时暂停空闲自动休眠及横屏充电停靠自动休眠；电源键和快捷菜单的手动休眠仍可使用。关闭开关后恢复自动休眠策略。

四种棋类游戏的离线对手在后台计算，使用扩展内存任务栈；如资源不足，可点“重试对手”再次计算，当前棋局和难度保持不变。

书架提供封面、图文、紧凑、画廊和聚焦五种样式，在筛选栏切换并记忆选择；紧凑列表不读取封面。封面视图第一页保留续读卡与六本书，第二页起隐藏续读卡并以 3×3 展示九本，横竖屏的书单连续且点击对应同一本书。上下翻页比较前后帧，只刷新变化区域；切换方向、覆盖层恢复和主动强刷仍保留完整刷新，实际闪烁与残影需设备测试。

在“系统设置 → 网络与连接 → 蓝牙翻页器”开启后查找并选择标准 BLE HID 翻页器，支持记忆配对、重连、断开、移除和反转按键方向。翻页键用于阅读翻页，在书首封面向后翻会进入正文第一页；弹窗、选文、工具、传输及休眠中不会误翻。暂不支持经典蓝牙；不同设备的 HID 按键映射和实际功耗仍需实机验证。

书架刷新会保留当前内容，等扫描和当前可见封面全部准备后统一更新。左右下角菜单共用内3／中5／外6的十四个直接功能位置；从菜单进入“编排”后，在相同位置拖动交换，点选替换或移除，支持撤销。点“完成”后才保存并同步左右两侧，返回或取消保留原布局。旧配置中已启用但未放置的功能仍可选用。

在“系统设置 → 网络与连接 → Wi-Fi”开启无线网络，选择附近的2.4 GHz网络并输入密码；连接成功后保存，最多记忆8个网络。点网络行右侧箭头可查看详情、设置自动连接或确认忘记。Wi-Fi在离开设置后保持连接，配网不要求先装存储卡。企业认证网络与网页登录认证暂不支持。

在“系统设置 → 存储与传输”选择“同一 Wi-Fi”“设备热点”或“USB U 盘”。同网方式让手机和阅读器连接相同网络后扫码打开网页；热点方式先扫连接码、保持连接，再切换“打开网页”扫码。网页无需安装应用，支持选择多个TXT/EPUB或TF卡TTF字体，显示逐文件结果；网络中断或超时后保留当前选择，重连只重试未成功的文件。同名替换仍需单独确认。

USB 方式需要支持数据的连接线和可用的 TF 卡。开启后，电脑会识别一个 TF 卡磁盘：TXT/EPUB 放入 `books/`，TTF 字体放入 `fonts/`。传输期间设备暂停阅读、TF 卡字体和无线传书，正常调试串口也会暂时消失。完成后先在电脑弹出磁盘，设备自动停止 USB、重新挂载并检查卡片，再恢复本机访问；若电脑未发送弹出通知，可在设备上选择“安全结束 USB 传输”，确认已在电脑弹出。失败时保持暂停并提供重试，不自动格式化；普通拔线不能代替电脑弹出。USB 仅提供 TF 卡，不暴露内部存储。

从“系统设置 → 存储与传输 → TF 卡与笔记”进入“TF 卡与存储”，可查看卡片、文件系统、容量和检查结果，重新挂载或两次确认后清空。格式化会删除整张 TF 卡的全部分区与文件，重建一个 FAT32 分区，再重新挂载并验证实际文件读写。exFAT 在本固件中需要显式格式化为 FAT32 才能使用；不会自动清卡，也不会清空设备内部存储。维护期间保持供电并避免拔卡。

设备点“完成，打开书架”后先确认结束，再等待接收任务退出，随后回到系统的本机书架。顶部返回、全局返回与快捷手势离开活动传书页也会先显示结束确认。本机书架读取 `books/` 和 TF 根目录直接存放的 TXT/EPUB，固件不再内置示例书籍或漫画；不递归读取其他文件夹。 从本机书架点书直接进入阅读；左右实体键翻页，中间实体键单击返回、双击打开主页切换、长按回书架，离开阅读时保存进度，轻点正文中部打开工具。字体页返回原书，普通返回保持在产品导航内。传书期间暂用内置字体，结束后恢复所选卡上字体。存储不可用时可前往“TF 卡与存储”检查，不会自动格式化或改用另一存储源。

本机图书内也可使用两角扇形快捷菜单与全局返回，正文左右滑动仍翻页。长按一个字后保持手指拖动，向前或向后扩展选区，松手后可保存划线或撰写批注；拖动首尾圆形手柄可继续微调。轻点选文、阅读工具、页码或插图确认弹窗外的空白只关闭浮层，不翻页或提交批注。“书签与笔记”按笔记、划线、书签分类，本书入口只显示该书记录，可返回原文、移除或导出；已保存划线自动参与休眠摘录。批注支持拼音26键/9键、英语和数字符号；已移除手写文字输入，旧笔迹附件仍保留。独立「画板笔记」的整张网点纸随屏幕旋转，横屏工具移到左侧，扩大书写范围；旧原稿完整等比显示，不裁切或拉伸。橡皮恢复背景网点，两侧实体键用于撤销和保存。定位绑定文件路径、文件大小、章节和解析正文的 UTF-8 范围；同路径同大小替换文件仍可能误匹配，请保留原书。

“TF 卡与存储”显示笔记的实际保存位置：内置存储可用时使用 `/flash/books/.pico-system`，否则使用 TF 书根的 `.pico-system`；已有记录不会被隐式搬迁或合并。最多保存1024条记录，每条笔记文字最多2047个 UTF-8 字节，编辑器显示字节计数和上限。记录使用独立对象与最终索引提交，按实际内容分配PSRAM，兼容读取旧记录及草稿。可在“TF 卡与存储 → 笔记与划线”显式合并另一处存储的记录，保留源库并跳过完整相同的记录；未保存输入、读取异常、容量不足或换卡时不会提交合并。停止输入约6秒后尝试保存脏草稿，拼音未选词或触摸操作中会延后；草稿写入失败不会单独阻断正式保存。只有显示“笔记已保存”才表示记录已写入；保存失败时编辑内容留在当前会话，请在关机前检查提示并重试。可选扩展拼音词库见[笔记输入说明](docs/INPUT_METHOD.md)。

阅读顶部在同样高度内分两行显示章节名和页码／百分比。过长章节名使用省略号，页码和百分比保留完整；不额外挤占正文。轻点阅读顶部的整个进度区域（含滑杆、页码与留白）可输入全书页码，使用宽松的数字键盘确认跳转；长按这个区域打开阅读工具，可调字号、开始选文和查看划线笔记。正文长按后拖动仍用于选文。输入页码期间不后台计数或连续刷新；确认后才按章计算所需的真实页码，进度提示局部刷新，可取消并返回原阅读位置。页码随字体、字号和横竖方向变化，批注仍绑定原文字节位置；切换排版后重新计算。滑杆单击不会按触点位置直接跳转；只有明确水平拖动才预览章节和全书百分比，松手后再定位，跳转后可通过独立的“返回原处”按钮返回。EPUB 的拖动百分比按原始章节字节比例估算，数字跳页使用实际分页。全局阅读快捷卡片和页码输入页均可打开目录，目录标出当前章节并支持点选跳转。正文与控件随产品横竖方向排布，实体键和普通左右滑翻保持可用。

WiFi 设置无需已有网络即可开启并自动扫描；无线启动或暂忙时会保留扫描请求，扫描失败和连接失败分别提示。也可在关闭状态直接点“添加网络”输入名称，再填写密码或选择开放网络，连接时自动开启；只在实际连接成功后记忆网络。

原有硬件演示页仍保留，传书演示页的“离页断网”不适用于原生系统的日常Wi-Fi。

## 传书与使用限制

AP 与已有 WiFi 均提供传书网页二维码；热点页可切换连接 WiFi 与打开网页二维码。设备显示的构建时间统一标注 UTC。

传书服务仅在传书页运行，离页停止。它使用局域网 HTTP，没有独立登录或 TLS；同网设备可管理当前上传存储中的图书，请使用可信网络。保存的 WiFi 凭据位于设备 NVS，公开接口和日志不返回密码。本版未启用 NVS/flash 加密，不以此提供物理访问防护。

停止传书后返回进入前的页面或菜单位置。检测到已挂载TF卡失效时，设备停止相关阅读/传书并回退字体；插回后需在TF页显式重新挂载。写入时拔卡可能损坏文件系统。EPUB会在显示当前页前自动加载本地JPEG/PNG插图，按正文宽高等比排版，整张换页、不拉伸或裁切；读取尺寸后固定分页几何，解码或缓存淘汰不改变页码。首次无阅读进度时展示书中声明的独立封面，轻点或向后翻进入正文，续读不重复打断；首章第一页向前翻可重新查看封面。封面不计入正文页数，已有章节与批注字节锚点不变。轻点正文图片先询问“全屏预览图片？”，选择“继续阅读”保留原页，选择“全屏预览”才打开大图并可返回原位置；绘图和后台预绘不读取文件或解码。ZIP条目、资源清单项和章节各最多32768个，OPF/导航元数据解压后最多4 MiB，正文/图片读取最多2 MiB，ZIP中央目录最多8 MiB；标题总预算1 MiB，超出后用编号标题；即使未使用的ZIP条目也不能超过4 MiB。以上内存与资源限制独立于章节数，并非章数合规就一定能打开；不支持ZIP64或超过32768项/章的文件；外部换书或换卡产生同路径、同大小文件时，旧阅读进度可能仍被匹配。保存失败的待重试状态不能保证在断电后保留。

进入书架时询问是否继续上次阅读，选择“留在书架”不会打开图书；确认“继续阅读”才加载（KEY1取消、KEY3继续）。先解析目录与当前章节，再完成起始两页或续读位置；其余分页每次补两页，其他章节按需加载。分页未完成时页数显示“…”；向前跨章到上一章末页仍需完成该章分页。字宽测量使用驻留字体表，不提前生成整章字形位图。打开图书和加载章节时保留等待提示；失败显示可见原因（内存不足、超出限制、格式不支持或文件异常）。 点击本机图书会先推送带文件名的静态载入页，再在后续一轮读取字体和解析图书，避免点击后长时间停在旧画面。

滑动翻页在抬手时提交，距离阈值由120像素缩短到64像素；超过24像素轻点容差但不足64像素的短拖仍取消。在正文插图或失败占位上滑动仍翻页，不误开图片预览。

插图范围：基线 JPEG 优先在解码时缩小，允许最多放大两倍到显示尺寸以减少计算，原图最多16M像素、单边8192；PNG及渐进 JPEG 原图最多1M像素，解码堆上限4 MiB。输出不超过648×1000灰度像素，透明 PNG 合成白底。正文图片缓存上限为1,296,000字节、64幅，优先淘汰当前页以外的图片，离开章节时释放；独立放大预览仍可复用最近查看的一幅图。缺失、损坏、超限或不支持的图片在正文保留不可用占位，轻点并确认全屏预览后可重试并查看原因，不阻断阅读，也不改变已确定的分页。重复图片的已读最早节号仅在单独预览中提示；章首连续图片紧接标题时，预览使用“标题图”说明，不显示最早位置。历史只来自本次已读章节，关闭图书后清空，不扫描未读章节，不声称是全书首次出现；不同路径下的相同内容不作匹配。支持 SVG 包装中的本地 JPEG/PNG 引用，不绘制纯 SVG 矢量、CSS背景或外链图片；普通 TXT 不虚构封面。解码器来源与许可见 [第三方说明](main/book/vendor/README.md)。

默认完整字库采用官方原版 MiSans 可变字体，作为本软件组件随 `sdcard/fonts/MiSansVF.ttf` 提供。将部署包的 `fonts/`（含许可证）复制到 TF 卡根目录，固件默认按需读取 `/sdcard/fonts/MiSansVF.ttf` 并支持调节字重；已明确保存的字体选择会保留。TF 卡或字体不可用时回退到仅覆盖界面与示例文字的内置子集，任意外部图书仍需完整字库。其他完整 TrueType 字体可在“字体”页选择。WiFi 网页也可上传到 `/sdcard/fonts`：每个 TTF 上限 32 MiB，仅接受 TrueType 轮廓（不支持 OTF/CFF、TTC、WOFF）。上传前检查容量，同名替换需确认，失败保留旧字体；传输期间暂用内置字体，结束后恢复所选卡上字体。详见 [TF 部署及字体许可](sdcard/README.md)。

功能变化见 [版本变更](docs/CHANGELOG.md)。离线拼音字表来自 pypinyin（MIT），见 [组件许可与再生成说明](components/read_pico_search/README.md)。
