# 历史笔迹兼容 / Legacy ink compatibility

手写文字输入、识别器和TF模型分发已撤下。笔记文字输入保留拼音26键、拼音9键、英文和数字符号；独立画板笔记继续提供直接绘画。

Handwriting text input, its recognizer and TF model distribution have been removed. Note text input retains pinyin QWERTY/T9, English and numbers/symbols; the independent drawing-notes app still supports direct drawing.

旧版笔记与草稿中的64点笔迹附件保持原存档格式，仍可查看、随文字保存和导出附件说明。旧手写输入偏好回退为拼音，不更改其它已存输入偏好。升级不访问或删除用户TF卡上的旧手写模型和笔迹数据。

Legacy 64-point note/draft attachments retain their original storage format and remain viewable, saveable with text and described in exports. A retired handwriting preference falls back to pinyin without changing other stored mode IDs. Upgrades neither access nor remove old handwriting models or user ink on TF.

当前行为及存储边界见[笔记输入](INPUT_METHOD.md)；独立应用说明见[TF应用](TF-APPS.md)。

See [note input](INPUT_METHOD.md) for current behavior/storage boundaries and [TF apps](TF-APPS.md) for independent drawing.
