Read Pico は、Read シリーズの開発ボードです。ESP32-S3 と 4.7 インチのモノクロ電子ペーパーディスプレイを搭載しています。
Shenzhen MindReset Technology Co., Ltd. が、電子ペーパー向けのオープンソースファームウェアを
開発する方に向けて提供しています。このリポジトリには、ボードに出荷時から搭載されるファームウェアが含まれています。

ディスプレイ、タッチ、加速度センサー、電源、キー、TF カード、フォント、スリープと復帰の
デモ画面と診断画面を個別に用意しています。ハードウェアの動作確認や、独自ファームウェアを
開発する際のリフレッシュ制御、電力管理、操作方法の参考として利用できます。

ボードサポート、PMU プロトコルのホスト実装、各チップのドライバーは独立したコンポーネントとして
再利用できます。本ファームウェアはハードウェアのデモであり、完成した電子書籍リーダーではありません。

AI エージェント向けのディレクトリ構成、`app_desc_t` の仕様、用語集、コメント規約は
[AGENTS.md](AGENTS.md) を参照してください。

## ハードウェア

| 項目 | 仕様 |
| --- | --- |
| MCU | ESP32-S3、16 MB flash、8 MB Octal PSRAM。flash と PSRAM はいずれも 120 MHz で動作 |
| ディスプレイ | 4.7 インチのモノクロ電子ペーパー、1216 × 684、16 階調、LCD ペリフェラルで駆動する 16 bit パラレルインターフェース |
| 電子ペーパー電源 | SY7636A。PGOOD は IO エキスパンダー経由で読み取り |
| 電源管理 | CW32L010。独自の I2C プロトコルでバッテリー、充放電、インジケーター LED、RTC、アラーム、電源を制御 |
| タッチ | CST836U、2 点タッチ、割り込み、ディープスリープからの復帰 |
| 加速度センサー | SC7A20H、タップ、向き検出、自由落下、FIFO |
| IO エキスパンダー | FCA9555、電子ペーパー制御ピンとカード検出 |
| ストレージ | TF カード（1 bit SDMMC）。フォントはカードから読み込み |
| その他 | ブザー、3 つの静電容量式キー領域 |

## ビルドと書き込み

ESP-IDF v6.1 が必要です。`components/read_pico/read_pico_flash_hpm.c` は、
v6 でのみ提供される `esp_flash_chips/spi_flash_override.h` に依存しています。

```sh
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/cu.usbmodem* flash monitor
```

`sdkconfig.defaults` の 120 MHz flash / PSRAM タイミングは、ボードに搭載された flash の型番に依存します。
CI は `sdkconfig.ci` の標準タイミングを使い、コンパイルできることのみを確認します。
[.github/workflows/build.yml](docs/ci/upstream-build.yml) を参照してください。

開発中や書き込み時に、スリープから復帰したデバイスが認識されない場合は、次の順に試してください。

1. USB Type-A のデータケーブルに交換する。
2. デバイスを再度スリープさせてから復帰させる。
3. ボードを再起動してやり直す。

パネルの共通電圧（VCOM）は工場で校正され、PMU に保存されます。ファームウェアは起動時に
一度だけ読み取り、ドライバーを設定します。ローカルには保存せず、ユーザーによる変更機能もありません。

| 読書テスト | 内蔵テキスト、DU / GL16 / GC16 によるページ送り、ヘッダーでの文字サイズ調整 |
| タッチ | 連続 DU による 2 点追従、指を離した後の全画面更新、ディープスリープと自動復帰 |
| 加速度センサー | リアルタイムの 3 軸値と傾き、タップ回数、向き検出 |
| 加速度センサー診断 | サンプリング設定とセルフテスト |
| 電源とバッテリー | バッテリー電圧、残量、充電状態。電子ペーパーの電源レール、温度、異常、読み取り専用の SY7636A 設定 |
| PMU プロトコル | プロトコルの状態、イベント、設定、コマンド |
| 電源キー | `key_raw_events`、押下・解放時のレベル、DOWN/UP/SHORT/LONG イベント |
| スリープと復帰 | ライトスリープ（キー操作または持ち上げで復帰）、ディープスリープ、電源オフ |
| TF カードとブザー | カード容量とマウント状態、再マウント、フォーマット、ブザー |
| フォント | カード内の TTF の一覧と切り替え、組版プレビュー、ウェイトの順次切り替え |
| IO 拡張 | Port-0 のレベルと割り込み、下部バーからのタッチリセットパルス |
| デバイス機能テスト | デバイスの応答確認とコマンド ACK。電源断を伴う項目はバックエンドにのみ結果を記録 |
| 図書 | TF カードまたは内蔵ストレージの UTF-8 / GBK TXT と EPUB、目次、文字サイズ、本ごとの読書位置。左右スワイプでページ送り、本文の長押しとドラッグで文字を選択、本棚項目の長押しで詳細表示、読書位置の消去、確認付き削除。保存先フィルター、名前・最近読んだ順の並べ替え、ピンイン・頭文字・英語での検索に対応。単独操作はポップアップ、管理ページは複数選択、読書位置の消去・削除、再スキャンに対応。振って次ページへ進む実験機能は既定で無効。EPUB は NCX と nav の目次に対応。 |
| 転送 | 端末のホットスポットまたは既存の WiFi に接続し、ブラウザーで TXT/EPUB を転送。TF カードへの完全な TTF フォントのアップロードにも対応。QR コードでホットスポットに接続できます。既存の 2.4 GHz WiFi はタッチ画面で選択し、パスワードを入力できます。Web 設定も利用可能です。TF カードを優先し、内蔵ストレージは1ファイル1 MBまで。ブラウザーでは現在の転送先の本を一覧・検索し、置換・削除を確認できます。転送のキャンセル・再試行と端末での保存済みWiFiの削除にも対応。ページを離れると停止。 |

従来の図書デモでは、KEY1 / KEY2 / KEY3 は前ページ / ツールバー / 次ページです。ツールバーには全画面更新があります。中央キーを500 ms長押しするとデモメニューを開けます。他のデモページでは KEY2 の全画面 GC16 更新と KEY3 のメニューを維持します。メニュー項目は指を離すと確定し、外へ滑らせるとキャンセルします。

## ネイティブシステムの Wi-Fi 設定とファイル転送

対応端末の Lingxi Board はデバッグ USB から画面を直接受信し、TF カードを端末で利用し続けられます。自動更新はバックグラウンドに保存し、手動送信ではタッチ操作終了後の表示を要求できます。ロック中はロックを維持します。ファイル管理は別の TF ディスク引き渡しを使用し、完了後に安全な取り出しが必要です。

現在のネイティブシステムは **XH View OS For Pico 0.39.1-dev69** の先行プレビューテスト版（画面表示は「先行预览测试版」）です。「システム設定」は用途別の6グループに分かれています。

| グループ | 機能 |
| --- | --- |
| ストレージと転送 | 転送ハブを直接開く：同じ Wi-Fi、端末ホットスポット、USB ディスク、TF カードとノート、本体の本を開く |
| ネットワークと接続 | Wi-Fi、スマートフォンとパソコンの管理、Bluetooth ページ送り |
| 読書と入力 | 読書レイアウト、ノート入力 |
| 外観と操作 | ホームのナビゲーション、クイックメニュー、通知音 |
| アプリとサービス | アプリ一覧、Home Assistant、3D プリンター、ボードゲーム |
| システムと電源 | 電源とロック画面、日付と時刻、スリープ抑止 |

上部のシステム情報カードをタップすると「この端末について」が開き、正式なシステム名、テスト版の表示、バージョンを確認し、初回ガイドを再開できます。子設定からは所属グループ、設定ホーム、元の画面の順に戻ります。

静止した起動画面にも同じシステム名、バージョン、テスト版の表示を使い、パネルのネイティブ16階調で描画します。

「システム設定 → システムと電源 → 保持唤醒」のスイッチは既定でオンとなり、選択を保存します。オンの間は無操作時の自動スリープと横向き・充電中のドック自動スリープを停止します。電源キーやショートカットによる手動スリープは使用できます。オフにすると通常の自動スリープに戻ります。

4種類のボードゲームの対戦相手は、外部メモリのスタックを使うバックグラウンドタスクで思考します。リソースが不足した場合は「対戦相手を再試行」で再計算でき、対局と難易度は維持されます。

本棚のフィルターバーで表紙、表紙付きリスト、コンパクト、ギャラリー、フォーカスを切り替え、選択を保存します。コンパクト表示では表紙をデコードしません。表紙表示の1ページ目には前回読んだ本と6冊を表示し、2ページ目以降は前回のカードを隠して3×3の9冊表示にします。縦横どちらも本の順序とタップ位置が一致します。ページ送りでは前後の差分領域を更新し、回転・オーバーレイ復帰・明示的な清掃では全体更新を維持します。実際の点滅や残像は実機検証が必要です。

「システム設定 → ネットワークと接続 → Bluetooth ページ送り」を開きます。有効にして標準BLE HIDリモコンを検索・選択すると、ペアリング保存、再接続、切断、登録削除、方向反転を利用できます。読書中のページ送りに使用し、冒頭の表紙で次へ送ると本文の先頭へ進みます。ダイアログ・文字選択・ツール・転送・休眠中は操作を抑止します。従来のBluetoothには非対応で、機種ごとのキー互換性や消費電力は実機で確認してください。

本棚の更新では、スキャンと表示対象の表紙の準備が終わるまで現在の画面を保ち、結果を一度に表示します。両隅のメニューは内3・中5・外6の14個の直接操作を共有します。配置編集では実際の位置へドラッグして交換し、タップで変更・削除でき、元に戻す操作も使えます。「完了」で両側に保存し、戻る操作やキャンセルでは元の配置を保ちます。以前有効で未配置の機能も選択できます。

「システム設定 → ネットワークと接続 → Wi-Fi」で Wi-Fi を有効にし、近くの 2.4 GHz ネットワークを選んでパスワードを入力します。接続に成功したネットワークは最大8件まで保存します。各行の右矢印から詳細を開き、自動接続の設定や確認付きの登録削除ができます。設定画面を離れても接続を維持し、初期設定にストレージカードは必要ありません。企業向け認証や Web ログイン認証が必要なネットワークには対応していません。

「システム設定 → ストレージと転送」で、同じ Wi-Fi、端末ホットスポット、USB ディスクのいずれかを選びます。同じ Wi-Fi を使う場合は、スマートフォンとリーダーを同じネットワークに接続し、Web ページの QR コードを読み取ります。ホットスポットの場合は接続用コードを先に読み取り、接続したまま「Web ページを開く」コードに切り替えます。アプリのインストールは不要です。複数の TXT/EPUB や TF カード用 TTF を選択し、ファイルごとの結果を確認できます。通信切断やタイムアウト後も選択を保持し、再接続時は未完了のファイルだけを再試行します。同名ファイルの置換には別途確認が必要です。

USB 転送にはデータ対応ケーブルと使用可能な TF カードが必要です。有効にすると、パソコンに TF カードのディスクが表示されます。TXT/EPUB は `books/`、TTF は `fonts/` に置いてください。USB がカードを使用している間は読書、カード内フォント、無線転送を停止し、通常のデバッグ用シリアルポートも一時的に消えます。完了後は先にパソコンでディスクを取り出してください。端末が USB を停止し、カードを再マウント・検査してから本体でのアクセスを再開します。パソコンから取り出し通知が届かない場合は、端末の「USB 転送を安全に終了」を選び、パソコン側で取り出したことを確認します。終了に失敗した場合はアクセスを停止したまま再試行でき、自動フォーマットは行いません。ケーブルを抜くだけではディスクの取り出し操作の代わりになりません。USB で公開するのは TF カードのみで、内蔵ストレージは公開しません。

「システム設定 → ストレージと転送 → TF カードとノート（TF 卡与笔记）」から「TF カードとストレージ」を開き、カード、ファイルシステム、容量、検査結果を確認し、再マウントまたは2回の確認後の消去を行えます。フォーマットは TF カード全体の全パーティションとファイルを削除し、FAT32 パーティションを1つ作成して再マウントし、実際のファイル読み書きを検証します。本ファームウェアで exFAT カードを使用するには、明示的に FAT32 へフォーマットする必要があります。カードの自動消去や内蔵ストレージの消去は行いません。処理中は電源を維持し、カードを抜かないでください。

「完了して本棚を開く」では転送終了を確認し、受信処理の終了を待ってからネイティブの本棚へ戻ります。上部の戻るボタン、全体の戻る操作、クイックジェスチャーでも、転送中の画面を離れる前に終了を確認します。本棚は `books/` と TF カードのルートに直接置いた TXT/EPUB を読み込み、内蔵サンプル書籍や漫画は含みません。他のフォルダーを再帰的には検索しません。この本棚から開いた本では、中央キーの短押しで戻る、2回押しでホーム切り替え、長押しで本棚へ戻り、読書を離れる時に位置を保存し、左右のキーでページを送ります。転送中は内蔵フォントを使い、終了後に選択済みのカード内フォントへ戻します。ストレージが使用できない場合は「TF カードとストレージ」で確認でき、自動フォーマットや別の保存先への自動切り替えは行いません。

実際のローカル本でも両隅のクイックメニューと全体の戻る操作を利用でき、本文の左右スワイプでページを送れます。文字を長押ししたまま前後にドラッグして範囲を選び、指を離すとハイライトや注釈を保存できます。両端の丸いハンドルで範囲を調整できます。選択、読書ツール、ページ入力、画像確認のパネル外をタップすると、ページ移動や注釈保存を行わずパネルだけを閉じます。記録はノート・ハイライト・しおり別に表示し、本の入口ではその本だけを表示します。原文への移動、削除、書き出しに対応し、ハイライトはスリープ抜粋に自動で加わります。注釈にはピンイン26キー/9キー、英語、数字・記号を利用できます。手書き文字入力は削除しましたが、既存の筆跡添付は保持します。独立した画板ノートはドット入りの用紙全体を画面と一緒に回転します。横画面ではツールを左側に移し、既存の原稿は切り取りや引き伸ばしをせず全体を表示します。消しゴムはドットを復元し、両端の実体キーは取り消しと保存に使います。位置はパス、元ファイルサイズ、章、解析済み UTF-8 範囲に関連付けます。同じパスとサイズで別の本に置き換えると誤一致する場合があります。

「TF カードとストレージ」に実際のノート保存先を表示します。内蔵ストレージが使用可能な場合は `/flash/books/.pico-system`、それ以外は TF の書籍ルートの `.pico-system` を使い、既存の記録を暗黙に移動・統合しません。記録は最大256件、1件の本文は UTF-8 で383バイトまでで、編集画面に上限を表示します。実際の件数だけを書く2世代の分割保存は、旧固定長ブロックと旧記録も読み込めます。変更した下書きは約6秒の無操作後に保存し、未変換のピンインやタッチ操作中は延期します。下書きの書き込み失敗だけでは正式保存を中止しません。「筆記已保存」の表示で保存を確認できます。失敗した内容は現在のセッションに保持するため、電源を切る前に表示を確認して再試行してください。拡張ピンイン辞書は[ノート入力](docs/INPUT_METHOD.md)を参照してください。

読書バーは高さを変えず、章題とページ番号・割合を2行に分けます。長い章題は省略記号を使い、数字は省略せず、本文の領域も維持します。読書画面上部の進捗領域全体（バー、ページ表示、余白）をタップすると、全体のページ番号を数字キーボードで入力できます。長押しすると文字サイズや選択、ハイライトとメモの読書ツールを開きます。本文の長押し・ドラッグによる選択はそのまま使えます。入力中はページ計算や連続再描画を行わず、確定してから現在のフォント、サイズ、向きで必要なページを章ごとに計算します。進捗は部分更新し、キャンセルできます。バーのタップだけでは位置を移動しません。明確な横ドラッグ中は章と割合をプレビューし、指を離してから移動します。移動後は専用のボタンで元の位置へ戻れます。EPUB のドラッグ割合は元の章バイト数に基づく概算で、数字入力は実際のページ分割を使用します。数字入力画面と読書ショートカットから目次を開けます。本文と操作部は製品の縦横方向に合わせ、物理キーと通常の左右スワイプも使用できます。

WiFi 設定は保存済みネットワークなしでも有効化・自動スキャンできます。無線の起動中や一時的なビジー状態でもスキャン要求を保持し、スキャン失敗と接続失敗を別々に表示します。オフのまま「添加网络」から名前とパスワード、またはオープン認証を入力し、接続操作で WiFi を有効にできます。接続成功後だけ記憶します。

従来のハードウェアデモページも引き続き利用できます。転送デモの「画面を離れるとネットワーク停止」という動作は、ネイティブシステムの日常的な Wi-Fi 接続には適用されません。

## 転送と制限事項

AP と既存 WiFi の両モードで転送ページの QR コードを表示します。AP では WiFi 接続用とページを開くコードを切り替えられます。端末のビルド日時は UTC と明記します。

転送サーバーは転送画面でのみ動作し、画面を離れると停止します。個別ログインや TLS のないローカル HTTP を使用し、同じネットワークの端末から対象ストレージの本を管理できるため、信頼できるネットワークで使用してください。WiFi 認証情報は端末 NVS に保存され、公開 API やログにパスワードを返しません。NVS/flash 暗号化は有効化しておらず、物理アクセスへの保護は提供しません。

転送を停止すると、入る前の画面またはメニュー位置に戻ります。マウント済みTFカードが使用できなくなると、関連する読書・転送を停止し、内蔵フォントに戻ります。再挿入後はTF画面で明示的に再マウントしてください。書き込み中にカードを抜くとファイルシステムが破損する可能性があります。EPUBは現在ページの表示前にローカルJPEG/PNG挿絵を自動で読み込み、縦横比を保って本文に組み込みます。画像は切らずに全体を次ページへ送り、引き伸ばしません。事前に調べた寸法を使い、デコードやキャッシュ解放でページ位置を変えません。保存済み進捗のない初回は宣言された表紙を表示し、タップまたは次ページ操作で本文に進みます。再開時は表紙を挟まず、本文の最初で前ページ操作をすると表紙を見直せます。表紙は本文ページ数に含めず、章と注釈のバイト位置を維持します。挿絵をタップすると全画面プレビューの確認を表示します。「読書を続ける」で元のページに留まり、確認後のみ拡大します。画像上の左右スワイプは本文の改ページとして動作し、確認画面では改ページや直前のタッチ入力を通しません。描画とバックグラウンド事前描画ではファイルを読みません。ZIPエントリー、manifest項目、spine章はそれぞれ最大32768件、OPF・ナビゲーションは展開後4 MiB、本文・画像の読み込みは2 MiB、ZIP中央ディレクトリは8 MiBまでです。見出しの合計予算は1 MiBで、超過分は番号見出しになります。未使用エントリーも4 MiBを超えると拒否します。章数とは別にメモリー・リソース上限があり、ZIP64と32768件・章を超える本は非対応です。外部で置き換えた本や別のカードのファイルが同じパス・サイズの場合、以前の読書位置が適用されることがあります。保存失敗後の再試行状態は、電源断後の保持を保証しません。

本棚に入ると前回の読書を再開するか確認します。キャンセルすると本を開かず本棚に留まります（KEY1でキャンセル、KEY3で再開）。目次と現在の章を解析し、最初の2ページまたは保存位置までを先に組版します。残りは2ページずつ追加し、他の章は必要時に読み込みます。未完了の総ページ数は「…」と表示し、前章の末尾へ戻る場合はその章全体の組版が必要です。文字幅は常駐フォント表から計算し、章全体の字形画像を事前生成しません。待機表示と失敗理由（メモリ不足・上限超過・非対応形式・ファイル異常）は引き続き表示します。 ローカル本を選ぶと、ファイル名付きの静的な読み込み画面を先に表示し、次のループで字体・ファイル読み込みと解析を始めます。

スワイプによるページ送りは指を離した時点で確定し、距離は120から64ピクセルに短縮しました。タップ許容範囲の24ピクセルを超え、64未満のドラッグはキャンセルします。挿絵上のスワイプでもプレビューを開かずページを送ります。

挿絵の上限：ベースラインJPEGはデコード時の縮小を優先し、表示サイズへの拡大を最大2倍まで許容し、元画像16M画素・各辺8192まで。PNGとプログレッシブJPEGは1M画素・デコードヒープ4 MiBまで。出力は648×1000以内のグレースケールで、透過PNGは白背景に合成します。本文画像のキャッシュ上限は1,296,000バイト・64枚で、表示ページ外から解放し、章を離れると解放します。別画面のプレビューは閲覧した1枚を保持して再利用します。欠落・破損・上限超過・非対応画像には本文中で利用不可の代替表示を残し、タップで再試行と理由の確認ができます。本文の読書や確定済みのページ分割には影響しません。繰り返し画像の既読最小節番号は個別プレビューでのみ示します。章頭の画像群に見出しが直続する場合、プレビューは「标题图」とし、最初の位置を省きます。履歴は今回開いてから閲覧した章のみで、本を閉じると消去し、未読章や全書で最初の出現とは断定しません。別パスの同一内容は照合しません。SVG内のローカルJPEG/PNG参照は対応し、純粋なSVGベクター・CSS背景・外部画像は非対応です。通常のTXTに表紙画像を作り足すことはありません。[デコーダーの出典とライセンス](main/book/vendor/README.md)も参照してください。

既定の完全フォントは公式オリジナルの MiSans 可変フォントです。本ソフトウェアの構成要素として `sdcard/fonts/MiSansVF.ttf` を同梱します。ライセンスを含む `fonts/` 全体を TF カードのルートへコピーすると、`/sdcard/fonts/MiSansVF.ttf` から必要に応じて読み込み、ウェイトを変更できます。明示的に保存したフォント選択は保持します。カードやファイルが使えない場合は UI・デモ本文用の内蔵サブセットに戻るため、任意の書籍には完全なフォントが必要です。別の完全な TrueType フォントは端末の字体ページで選択できます。Web から `/sdcard/fonts` へ1ファイル32 MiBまでの TTF をアップロードできます（TrueType アウトラインのみ、OTF/CFF・TTC・WOFF は非対応）。容量確認、同名置換の確認、失敗時の旧ファイル保持を行います。転送中は内蔵字体を使い、終了後に選択済みカード字体へ戻します。[TF 配置とライセンス](sdcard/README.md)を参照してください。

機能の変更は [変更履歴](docs/CHANGELOG.md) を参照してください。拼音データは MIT ライセンスの pypinyin に由来します。[ライセンスと再生成](components/read_pico_search/README.md)を参照してください。
